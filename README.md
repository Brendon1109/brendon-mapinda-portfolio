# Brendon Mapinda — Portrait & Lifestyle Creative

Personal portfolio for **Brendon Mapinda**, a portrait & lifestyle photographer and cinematic content creator based in Cape Town, South Africa.

> *Portraits and visuals designed to feel timeless.*

## What it shows

- **Editorial Portraits** — magazine-style portrait sessions
- **Lifestyle Photography** — natural, elevated lifestyle content
- **Cinematic Reels** — short-form vertical video for Instagram and TikTok
- **Event Coverage** — birthdays, graduations, baby showers and brand events

## Tech stack

- HTML5, modern CSS (custom properties, grid, fluid type)
- Vanilla JavaScript (IntersectionObserver for reveal + active nav)
- Google Fonts: **Fraunces** (display) + **Inter** (body)
- Font Awesome 6 icons
- Hosted on GitHub Pages

## Structure

```
brendon-mapinda-portfolio/
├── index.html                # Single-page site
├── qr-code-generator.html    # QR utility (separate page)
├── css/styles.css            # Design system + page styles
├── js/script.js              # Nav + reveal interactions
├── images/                   # Portrait + assets
├── assets/                   # PDFs / press
├── favicon.svg
├── sitemap.xml
├── robots.txt
└── README.md
```

## Local development

```bash
# any static server works
python -m http.server 8000
# or
npx serve .
```

Then open <http://localhost:8000>.

## Deployment

Pushes to `main` are served automatically by GitHub Pages at
